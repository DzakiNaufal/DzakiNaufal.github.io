Proyek 02 · Python Logika

Cek Bilangan

Fungsi ringkas untuk menentukan klasifikasi angka: apakah bilangan tersebut bernilai netral, positif, atau negatif. Latihan dasar struktur kondisi bertingkat dan penanganan argumen.

cek-bilangan.py 8 Baris
Unduh .py ↘ 
def argumenAngka(angka):
    if angka == 0:
        print("Angka", angka, "adalah Netral")
    elif angka > 0:
        print("Angka", angka, "adalah positif")
    else:
        print("Angka", angka, "adalah negatif")

argumenAngka(-5)
Contoh Eksekusi Terminal bash · python3
$python3 cek-bilangan.py Angka -5 adalah negatif # Pengujian di interpreter interaktif dengan argumen lain: >>> argumenAngka(0) Angka 0 adalah Netral >>> argumenAngka(42) Angka 42 adalah positif

Catatan & Bedah Alur

1. Evaluasi Batas Nol

Logika kondisi memeriksa angka == 0 terlebih dahulu untuk menangkap kasus netral sebelum menguji perbandingan relasional angka > 0. Ini menghindari kerancuan definisi angka nol.

2. Penggunaan Argumen Fungsi

Dengan membungkus logika ke dalam fungsi bernama argumenAngka(angka), instruksi dapat dipanggil berkali-kali secara fleksibel dengan nilai uji berbeda tanpa menduplikasi kode.

3. Evaluasi & Catatan Jujur

Saat ini fungsi langsung memanggil print(). Dalam penerapan nyata, fungsi yang lebih fleksibel sebaiknya mengembalikan nilai string (return) agar hasil klasifikasi dapat diolah kembali oleh bagian program lainnya.
