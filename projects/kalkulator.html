Kalkulator Sederhana

Latihan logika pemrograman dasar dengan Python: memecah operasi aritmetika ke dalam fungsi modular, menerima input angka di terminal, dan mengarahkan alur perhitungan dengan percabangan kondisi.

Unduh .py ↘ 
import math

def tambah(a, b):
    return a + b

def kurang(a, b):
    return a - b

def kali(a, b):
    return a * b

def bagi(a, b):
    return a / b

def akar(a):
    return math.sqrt(a)

print("==== Kalkulator Sederhana ====")
a = float(input("Masukkan nilai a = "))
b = float(input("Masukkan nilai a = "))
print("1. Tambah")
print("2. Kurang")
print("3. Kali")
print("4. Bagi")
print("5. Akar (hanya nilai a)")
pilihan = int(input("Masukkan Pilihan = "))

if pilihan == 1:
    print("Hasil dari {} + {} = {}".format(a, b, tambah(a, b)))
elif pilihan == 2:
    print("Hasil dari {} - {} = {}".format(a, b, kurang(a, b)))
elif pilihan == 3:
    print("Hasil dari {} * {} = {}".format(a, b, kali(a, b)))
elif pilihan == 4:
    print("Hasil dari {} / {} = {}".format(a, b, bagi(a, b)))
elif pilihan == 5:
    print("Akar kuadrat dari {} = {}".format(a, akar(a)))
else:
    print("Pilihan tidak valid!")

Catatan & Bedah Alur

1. Modularisasi Fungsi

Setiap operasi matematika dipisahkan ke dalam fungsi tersendiri (tambah, kurang, kali, bagi, akar). Ini membuat alur komputasi terisolasi dan mudah diuji secara independen.

2. Tipe Data & Modul Eksternal

Input pengguna dikonversi secara eksplisit menjadi float agar mendukung bilangan berkoma, sedangkan nomor menu dikonversi ke int. Untuk akar kuadrat, script memanfaatkan fungsi sqrt dari modul standar math.

3. Evaluasi & Catatan Jujur

Script ini masih rentan crash jika pengguna membagi angka dengan nol (ZeroDivisionError) atau memasukkan teks saat diminta angka (ValueError). Langkah penyempurnaan berikutnya adalah membungkus pembagian dan input dengan blok try...except.
