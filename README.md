# Dzaki Naufal — Personal Developer Portfolio

[![Live Site](https://img.shields.io/badge/Live_Demo-dzakinaufal.github.io-2563eb?style=flat-square&logo=githubpages&logoColor=white)](https://dzakinaufal.github.io/)
[![React](https://img.shields.io/badge/React-18-61dafb?style=flat-square&logo=react&logoColor=black)](https://react.dev/)
[![Vite](https://img.shields.io/badge/Vite-6-bd34fe?style=flat-square&logo=vite&logoColor=white)](https://vitejs.dev/)

Portofolio rekayasa perangkat lunak yang menampilkan proyek akademik TRPL dan eksperimen komputasi. Dibangun menggunakan React, Vite, dan CSS murni, di-deploy otomatis melalui GitHub Actions ke GitHub Pages.

## Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Modern CSS
- **Icons**: Devicon
- **Deployment**: GitHub Pages (GitHub Actions)

## Menjalankan Lokal

```bash
git clone https://github.com/DzakiNaufal/DzakiNaufal.github.io.git
cd DzakiNaufal.github.io
npm install
npm run dev
```
