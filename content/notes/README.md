# Catatan

Folder ini untuk draf tulisan yang nantinya ditampilkan di section Catatan.

Situs ini statis dan tidak memakai build step, jadi catatan **tidak dirender otomatis** dari Markdown. Alurnya:

1. Tulis draf di sini (Markdown bebas).
2. Setelah selesai, salin versi finalnya ke `index.html` pada `<li class="note-item">`.
3. Ubah status dari "Draf" menjadi tautan/tanggal.

Kalau belum ada tulisan yang siap, biarkan section Catatan menampilkan draf seperti sekarang — jangan diisi artikel palsu.
